## 📁 Projects

### 🔧 1. CNC Plotter
A CNC (Computer Numerical Control) plotter machine controlled via **GRBL firmware** flashed on an Arduino. The machine reads G-code commands sent from a PC over serial communication and moves a pen along the X and Y axes using stepper motors, allowing it to draw precise shapes, patterns, and text on paper automatically.

**Tech:** GRBL Firmware · Arduino · Stepper Motors · G-code

---

### 🐍 2. Snake Game
A classic Snake Game implemented in **C++** using computer graphics concepts. The player controls a snake that moves around the screen, eating food to grow longer while avoiding collisions with walls and its own body. The game features smooth animation, collision detection, and score tracking rendered through a graphical window.

**Tech:** C++ · OpenGL / Graphics Library
